Navigazione e sicurezza

Per consegnare le pagine, l’infrastruttura di hosting riceve dati tecnici come indirizzo IP, risorsa richiesta, data e ora e informazioni sul browser. Tali dati servono a erogare il sito, rilevare abusi e diagnosticare problemi. La base giuridica è il legittimo interesse all’erogazione e alla sicurezza del sito (art. 6, par. 1, lett. f, GDPR). I dati sono necessari per stabilire la connessione. Il fornitore di hosting può accedervi per le proprie funzioni tecniche. Questa versione è ospitata su GitHub Pages. GitHub registra e conserva l’indirizzo IP dei visitatori per finalità di sicurezza. Per i criteri di conservazione applicati dal fornitore e le informazioni sui trasferimenti internazionali, consulta l’informativa sulla privacy di GitHub.
